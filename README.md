# 📚 Projeto Livros MVC

Este é um projeto Java Web no modelo MVC (Model-View-Controller) utilizando JSP, Servlets e MySQL.  
O sistema permite listar, cadastrar, buscar e gerenciar livros por meio de uma interface simples construída em JSP, com persistência em banco de dados via DAO.

🚀 Tecnologias Utilizadas

Backend
- Java (JDK 8+)
- Servlets (Javax)
- JDBC + MySQL Connector
- JSTL (1.2)

Frontend
- JSP
- HTML/CSS
- JSTL para iteração de listas

Servidor
- Apache Tomcat 9.0.112

Banco
- MySQL
